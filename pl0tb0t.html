Overview

Pl0tb0t is a pen plotter and the operating system built around it. The hardware is a modified HPGL-era plotter driven over serial by a Raspberry Pi. The OS is a Python/PyQt desktop app that handles art generation, SVG-to-G-code conversion via vpype, job queuing, and plotter control — all in one interface.

A companion web page at 90percent.art/make lets you generate artwork in the browser and send it directly to the plotter queue over the network.
